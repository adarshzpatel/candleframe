# Version 0.2 design and verification

Decision date: October 2, 2026. Scope: remove the synthetic heatmap from the demo, add market selection and a read-only live feed, then support dragging both axes. This is an experimental PoC version, not a published release.

## Caller experience

```ts
const chart = createChart(container, {
  feed: createSimulatedFeed({ symbol: 'BTC/USD', interval: '1m' }),
});
chart.replaceFeed(createBinanceFeed({ symbol: 'ETH/USDT', interval: '5m' }));
chart.execute({ type: 'priceScale.set', minPrice: 2000, maxPrice: 4000 });
chart.execute({ type: 'priceScale.reset' });
chart.dispose();
```

The host selects a feed. The runtime cancels the old generation, resets its data and reconnects without remounting the renderer. UI gestures and agent commands edit the same document.

## Alternatives and synthesis

Two independent design passes considered different ownership boundaries.

| Candidate | Benefit | Cost | Decision |
| --- | --- | --- | --- |
| One adapter bound to a source, symbol and interval; `replaceFeed()` | Extends the existing connection model and keeps provider selection in the host | Recreates the connection for each selection; no central provider catalog | Selected for this slice |
| Runtime provider catalog with `setMarket()` and provider-managed history/streams | Supports discovery, capability negotiation and shared subscriptions | Adds provider registration, resolution and more lifecycle states before those callers exist | Deferred until paging or shared feeds justify it |

The chosen design adopts independent stream status, instrument metadata, explicit market identity and drawing-anchor preservation from the catalog proposal. It does not introduce a registry or make the host coordinate history/socket ordering. Each live adapter owns that reconciliation behind `connect()`.

## Ownership and state

- `FeedDescriptor` identifies the provider, instrument, interval, units, precision and depth semantics. The adapter publishes validated metadata before live data.
- `ChartRuntime` owns candles, book reconstruction, indicators, stream status, data revisions and documents. Replacing the feed increments a generation before disposal; callbacks from old generations cannot mutate state.
- `createChart` owns canvases, coordinates, interaction and rendering. It clears hover and in-progress drawings on a market replacement.
- The demo owns dropdowns, localStorage keys and dialogs. It exposes the same chart controller as `window.openchart`.
- The Binance adapter owns sockets, aborted requests, history overlap, retry timing and stale-stream detection. Full top-20 snapshots avoid pretending a partial-depth stream has contiguous normalized delta IDs.

A source or symbol change clears drawings. An interval change preserves their UTC time and price anchors but resets the viewport, price scale and undo. Paused selections remain empty until resumed. No simulated fallback is allowed for a failing live feed.

## Axis behavior

The time-axis gesture changes the visible duration exponentially from its pointer-down range, anchored at the right edge. The price-axis gesture changes the range around its original midpoint and switches to manual mode. Both use the initial drag bounds, so repeated pointer events do not compound the scale accidentally.

Manual price bounds live in `ChartDocument`, not transient canvas state. This lets streaming data, persistence, agents and GPU recovery share the same scale. Time and price reset independently. Bounds reject non-finite, inverted, nonpositive and sub-tick ranges. Axis hit areas and labels stay hidden before candle history arrives, and wheel/drag gestures cannot lock in an empty chart's placeholder range. Price gestures retain the time-following setting; time gestures disable following.

Transparent, focusable HTML axis hit areas provide directional cursors, keyboard controls and touch-action isolation. Pointer capture permits a drag to leave the axis. The chart cancels wheel scrolling while hovered and uses `touch-action: none` to keep touch drags from scrolling the page. Keyboard Tab navigation remains available. Price geometry carries per-instance clipping bounds so large candles and lines cannot bleed into volume. Date labels reduce their tick count when the width cannot fit them.

## Heatmap policy

The heatmap remains an optional engine experiment. It is absent from the demo, disabled by default and cannot be restored accidentally from a saved layout. The normal demo allocates no heatmap history or texture storage. Recorded depth, defined sampling and a usable presentation are prerequisites for a later heatmap demo.

## Vertical pan correction

A browser comparison with [OpenMarket](https://openmarket.xyz/chart/) on October 2 showed vertical plot translation after a manual price adjustment while price spacing stayed fixed. Our plot handler previously ignored vertical pointer movement and left prices in autoscale.

Plot drags now translate both ranges from their pointer-down values and commit them together. A small movement threshold distinguishes a click. Manual prices remain fixed after release; Fit or a plot double-click restores autoscale and live time. The demo skips unchanged market statistics and order-book formatting during these document edits. Browser checks confirmed a 180-pixel upward plot drag preserved the time viewport and price span, and a 60-by-50-pixel diagonal drag moved both ranges by the corresponding screen distance. Fit restored autoscale; an ordinary click retained it. This comparison establishes interaction behavior, not equivalent frame latency or a performance advantage.

## Wide-zoom pan correction

The old time limits assumed the viewport fit inside retained history. At 2,200 visible bars and 422 loaded candles, their lower bound exceeded their upper bound, so dragging in either direction selected the same start time.

Time panning now permits blank space on either side while retaining five loaded intervals at an edge. Existing outlying views can move back without a jump. A clamped drag discards pointer overshoot so reversing responds immediately. Tests cover short and wide views, the old crossover, both edges and outlying viewports. In the browser, an 80-pixel drag and its reverse restored the starting view at 2,200 bars; an eight-pixel reverse also moved immediately after reaching an edge.

## Pan and scale easing

The view now applies a short exponential response to plot dragging and a bounded cubic ease-out after release. It estimates velocity from recent pointer movement, discards stale velocity after a pause and starts reversals with the new direction. Time-history and positive-price limits constrain both the drag target and the release destination. New gestures and host commands cancel pending motion; feed replacement cannot inherit it.

Zoom, axis resizing, Fit/reset, restored ranges and autoscale changes use a separate presentation transition. The document holds the exact destination immediately. A shared interpolated geometry moves candles, axes, overlays and hit tests together. Retargeting starts from the current displayed position, and repeated feed updates with unchanged ranges do not restart the curve. Grabbing the plot during a transition commits its displayed ranges before panning. The host can disable pan and scale motion separately; both honor reduced-motion preferences.

The reference was [OpenMarket's chart](https://openmarket.xyz/chart/), observed through its public UI. These are our own timing choices, not a reconstruction of its implementation or a measured performance comparison.

The motion update passed all 48 tests and the production build. Browser checks confirmed a 120-pixel diagonal drag settled about 216 pixels horizontally with momentum, both axis drags changed their respective spans, Fit interrupted a glide and restored live time with automatic prices, wheel zoom preserved automatic prices, and panning remained reversible at 2,200 visible bars. Switching to paused ETH during a glide cleared the old view and retained the new market's default scales. Deterministic tests cover 30/60/120 Hz sampling, deceleration, cancellation, held pauses, bounds and scale continuity. Touch hardware and OS reduced-motion behavior remain unverified in the browser.

## Accepted tradeoffs

The live adapter supports three spot instruments and four fixed intervals. It supplies 360 initial bars and top-20 depth snapshots. Older-history paging, full-book diff reconstruction, exchange sessions, workers and a public provider catalog are deferred. The simulation restarts its deterministic clock on selection changes. Indicator execution is trusted host code. The public interfaces may change.

The changes retain one GPU geometry batch but do not establish a speed advantage. CPU submission is only one portion of frame latency. License selection and performance acceptance gates remain open.

## Verification, October 2, 2026

- All 39 automated tests passed. The production build, type check and headless example passed. Checks cover adapter reconciliation, gaps, cancellation, rate-limit cooldown, simulator aggregation, independent stream health, bounded state, document validation and both axis scales.
- The Chromium in-app browser displayed live ETH/USDT five-minute candles and top-20 depth. After rapid BTC/15m and SOL/1h selections, inspection showed SOL/USDT, 1h, generation 7, 360 candles and both streams live. The paused selection showed empty data until resumed.
- A 150-pixel rightward time-axis drag changed 180 visible bars to about 103 with the right edge fixed. A vertical price-axis drag enlarged prices without changing the time viewport. Reverse drags compressed both scales. Enlarged candles remained clipped above volume.
- Double-clicking the price axis returned to automatic scaling without moving time. Double-clicking the time axis restored live following. Keyboard scaling survived layout save/reset/restore, and the PNG preview decoded successfully.
- With focus on the Pause control outside the chart, a wheel gesture over the plot changed 180 visible bars to about 220 while page scroll stayed at zero. Tab from the price axis reached the external range controls. A paused market with no history ignored a wheel gesture, retained automatic scaling and kept the page still.
- Live ETH/USDT returned to healthy candle and depth streams after pause/resume. Browser console inspection reported no errors during the checked interactions.

The original v0.1 browser pass covered drawing creation/editing, layout save/restore, gap recovery, deliberate GPU loss/restoration and PNG preview. Native download-event capture timed out, so ordinary file-save behavior remains unverified. Safari, Firefox, touch hardware, screen readers, prolonged reconnects, memory leak profiles and comparative performance have not been certified.
