# Demo fonts

`paper-mono.woff2` is the unmodified Paper Mono variable WOFF2 (weights 100 to 800), distributed under the SIL Open Font License 1.1. See `Paper-Mono-OFL.txt`.

Source: [paper-design/paper-mono](https://github.com/paper-design/paper-mono) at commit `e6eaeceaef02e77e3db997711e07a16378de2bd7`, file `fonts/webfonts/PaperMono[wght].woff2`. Retrieved on 2026-10-10.

The demo uses it for prices, axes and annotations. The library defaults are unchanged. `scripts/copy-fonts.mjs` copies the license notice into the build output.
